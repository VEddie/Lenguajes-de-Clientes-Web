# Pasos para correr la aplicación:
1. Instalar extensión de VSC: "Live Server" por Ritwick Dey
2. Inicializar servidor local.
3. Cargar index.html en la carpeta matrix_solver.

## Descripción

Aplicación básica para la realización de operaciones con matrices cuadradas desde 2x2 hasta 10x10. 

## Funcionalidades:

1. **Suma**: A+B
2. **Resta**: A-B
3. **Multiplicación**: AxB
4. **Multiplicar A por escalar**: k * A
5. **Transpuesta de A**
6. **Determinante de A**
7. **Inversa de A**
8. **Matriz identidad**
